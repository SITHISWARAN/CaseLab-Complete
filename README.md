# CaseLab — Clinical Reasoning Simulator

A React + TypeScript + Vite single-page educational clinical case simulator.

## Requirements
- Node.js 18.18+ (Node.js LTS recommended)
- npm

## Run on Windows
Open Command Prompt or PowerShell in this folder, then run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173/).

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Notes
- The case is fictional and intended for education only.
- Progress is stored in the browser using local storage where implemented by the app.
- No backend or API key is required for the included experience.
